# Security policy

Please do not publish credentials, private URLs, customer data, payment details, or exploitable production information in a public issue.

For a suspected vulnerability in this repository, use a private GitHub security advisory or contact the repository owner through the private contact method configured on GitHub. Include the affected commit, reproduction steps, and impact. Do not include live secrets in the report.

The community stack is for local demos. Do not connect it to production databases, payment accounts, warehouse systems, or customer data.
